02 / 08
The Solution

A Luxury Dashboard
For Human Connection.

Greetify is more than a reminder app. It's a real-time, live-data birthday intelligence platform with a polished, animated UI and an enterprise-grade microservice backbone.

🎯
Smart Classification
Automatically groups contacts into Today, Upcoming 7-Day, Future Radar 30-Day, and Missed — live on every load.
⚡
Live Data, Zero Refresh
Contacts are fetched in real-time from MongoDB Atlas via a secure REST API. Every page load is always up to date.
✅
Wish Tracking
Mark contacts as "wished" with a persisted flag — never accidentally wish someone twice or forget who you've already greeted.
🎨
Premium Glassmorphism UI
A stunning dark dashboard with GSAP animations, typewriter effects, and a full custom Anti-Gravity design system.
📂
Bulk Excel Import
Upload contacts via .xlsx spreadsheets. The Node.js backend parses and imports them directly into MongoDB instantly.
🐳
One-Command Deploy
Fully containerised with Docker Compose. From clone to running in under 60 seconds with docker-compose up --build.

Polyglot Microservices,

☕ Java Layer — Frontend & Proxy
Serves the Thymeleaf HTML dashboard on port 8080. Acts as a secure proxy at /proxy/contacts — the browser never directly contacts the Node.js API, enabling independent scaling and security.
🟢 Node.js Layer — Data & Logic
Handles all data access via Mongoose ODM on port 4000. Exposes GET /api/contacts, manages file uploads, parses Excel imports, and connects to MongoDB Atlas over TLS.

05 / 08
Product Highlights

Built With
Obsessive Detail.

🎬 GSAP Animation System
Cinematic entrance animations with staggered card reveals, a live typewriter status bar, pulsing connection dot, and smooth hero fade-in sequences — all powered by GSAP 3.12.5.
🛡️ Proxy Security Layer
The Java layer acts as an API gateway — the browser sends requests only to the Spring Boot server, which forwards them internally. MongoDB credentials never touch the client.
📅 Intelligent Date Engine
Client-side JavaScript classifies every contact's birthday in real-time: Today's birthdays, Upcoming within 7 days, Future Radar within 30 days, and Missed birthdays this year.
🎨 Anti-Gravity Design System
A full custom CSS design system — dark glassmorphism, section accent colours, gradient stat pills, responsive grid layout, and self-hosted fonts for offline Docker environments.
📥 Excel Bulk Import
Upload a .xlsx spreadsheet of contacts and Greetify parses it instantly server-side using multer + xlsx, inserting all records into MongoDB in one operation.
📦 Fat JAR + Docker
The Java service compiles to a single executable fat JAR via Maven. Both services are Dockerised and orchestrated with Compose — environment-parity from dev to production.
